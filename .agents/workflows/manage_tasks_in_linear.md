# Manage Tasks in Linear

All AI agents MUST manage their tasks in Linear. Keep issue statuses strictly up to date to reflect your current progress.

## Workflow Rules

1. Before starting work across any milestone, always identify the corresponding issue in the designated Linear project.
2. If an issue for your task does not exist, create it in Linear under the appropriate project and team before proceeding.
3. Update the Linear issue status from `Backlog` / `Todo` to `In Progress` when actively working on it.
4. When work is confirmed complete and tested, move the issue status to `Done` (or `Completed`).
5. Track sub-tasks, stories, and findings as checklist items or comments within the parent Linear issue.
