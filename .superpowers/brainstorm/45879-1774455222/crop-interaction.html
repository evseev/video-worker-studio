Interaction Details

Hover State

  • Semi-transparent dark overlay (bg-black/40)
  • Move icon + "Reposition" text
  • Refresh button moves to top-right corner
  • Violet border hint on container
  • Cursor: grab

Drag State

  • Overlay disappears — see image move
  • Image pans under the fixed window
  • Cursor: grabbing
  • Clamped to edges (can't pan image off-screen)
  • On mouseup: save objectPosition to store
