Key Difference From Current System

Currently all scenes have 1 image slot and templates only change caption styling. These archetypes require different asset slot counts per scene (1 vs 2) and different Remotion layouts — this is a structural change that flows through the entire pipeline: AI generation → asset fetching → preview → rendering.
