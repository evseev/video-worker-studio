New Flow (5 steps)
1
Template ✦ NEW
Pick template archetype (Slideshow / Comparison / Fact Card)
Drives everything downstream
2
Idea
Enter topic → AI generates angles shaped by template
e.g., Comparison → "Celebrity couples: then vs now"
3
Script + Assets
AI generates template-shaped scenes → auto-fetch assets (1 or 2 per scene)
Scene structure matches template slots
4
Preview + Edit
Template-specific scene cards, swap assets per slot, edit text/labels
SceneCard adapts to template type
5
Render
Aspect ratio, quality, music, voiceover
Caption style removed (built into template)

Key Changes

  • Template step inserted as Step 1 — before any AI generation
  • Refine step removed — trend validation can be inline in Idea step or cut for MVP
  • Script + asset fetching merged — assets fetched right after scene generation
  • Caption style selector removed from Render step (baked into template)
  • Template selector removed from old Script step
